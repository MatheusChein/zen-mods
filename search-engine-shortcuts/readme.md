# Search Engine Shortcuts

A keyboard shortcut for each of your search engines. Press it and the URL bar opens straight into that engine, as if you had typed its alias and a space: `⌘Y` for YouTube, `⌃⌥W` for Wikipedia, whatever you like.

## Setting a shortcut

Open `about:keyboard` (Zen's keyboard shortcut settings) and find the **Search With** section. Every search engine that's turned on in Zen's search settings is listed there, with an empty shortcut. Pick the ones you want, like any built-in shortcut.

The same engines are also in the menu bar under **Tools → Search With**.

## Options

- **Use the shortcuts even on pages that have their own for the same keys**: on by default, so your shortcut always opens the URL bar, the way `⌘T` always opens a new tab. Turn it off to let pages keep their own shortcuts.

## Notes

- Engines you add or turn on later appear automatically. Engines you turn off disappear, but keep their shortcut for when you turn them back on. If `about:keyboard` is open at the time, reload it to see the change.
- A shortcut stays with its engine even if you rename the engine or change its alias.
- Pairs well with **Search Engine Splash**, which plays a splash in the engine's color when the bar opens this way.
- This mod is a small script, so it needs a Zen restart after installing or updating. Turning it off takes effect right away.
